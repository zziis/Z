# ZELZAL CHAT v2.1

نسخة مطورة من مشروع ZELZAL CHAT.

## الإضافات
- حذف الروم من الواجهة لمنشئ الروم أو مدير التطبيق.
- رسائل خاصة بين المستخدمين مع بحث بالاسم أو `@username`.
- عداد للرسائل الخاصة غير المقروءة + تنبيه داخل التطبيق عند وصول رسالة جديدة.
- إظهار **الاسم + @username** الحقيقيين داخل الرسائل بدل كلمة "مستخدم".
- لوحة مدير داخل التطبيق.
- المدير يستطيع البحث عن المستخدمين، مراسلتهم، وحظر/فك حظر الحساب.
- شريط ترحيبي/إعلاني قابل للتعديل من لوحة المدير.
- موسيقى هادئة اختيارية: نمطان داخليان أو رابط MP3 مخصص، ويمكن تشغيلها/إيقافها من الواجهة.
- واجهة محسنة للموبايل.

## التثبيت
1. افتح `config.js` وضع رابط Supabase وPublishable/Anon Key.
2. افتح Supabase > SQL Editor.
3. نفّذ ملف `supabase.sql` كاملًا.
4. أنشئ حسابك داخل التطبيق.
5. لجعل حسابك مديرًا، نفّذ هذا السطر في SQL Editor بعد استبدال البريد:

```sql
update public.profiles p
set role='admin'
from auth.users u
where p.id=u.id and u.email='YOUR_EMAIL@example.com';
```

6. ارفع الملفات إلى GitHub Pages.

## ملاحظات
- الموسيقى لا تبدأ تلقائيًا بسبب سياسات المتصفحات؛ المستخدم يضغط زر "موسيقى" مرة واحدة.
- رابط MP3 المخصص يجب أن يكون رابطًا مباشرًا يسمح بالتشغيل من المتصفح.
- الرسائل الخاصة محمية بـ RLS: لا يستطيع قراءة الرسالة إلا المرسل أو المستلم.


## تحديث v2.3
- شريط سفلي ثابت للموبايل: الرومات / الخاص / حسابي.
- الرومات تعرض عدد المتصلين الحاليين عبر Supabase Realtime Presence.
- منشئ الروم يضع رسالة ترحيب عند إنشاء الروم وتظهر عند الدخول.
- زر رجوع واضح داخل الروم والخاص، مع دعم زر رجوع الجهاز.
- تقليل المسافات في شاشة المحادثة على الهاتف.
- صوت قصير عند الإرسال والاستلام.
- الخاص يعرض: ✓ تم الإرسال، ✓✓ مستلم، ✓✓ تمت القراءة.
- الروم يعرض ✓ بعد الإرسال و✓✓ عندما يقرأ عضو آخر الرسالة.
- حسابي: تعديل الاسم واليوزر، تسجيل الخروج، حذف الحساب نهائيًا.
- الشريط الإعلاني في الأعلى يبقى تحت تحكم مدير التطبيق.
- الموسيقى: المدير يضع اسم ورابط MP3 من لوحة الإدارة، والمستخدم يشغل/يوقف من نافذة الموسيقى.

مهم: شغّل ملف supabase.sql الجديد في SQL Editor قبل تجربة الميزات الجديدة.


## تحديث v2.4 — الصور والرسائل الصوتية
- إرسال صورة داخل الرومات والرسائل الخاصة.
- اختيار الصورة من معرض الهاتف.
- تسجيل رسالة صوتية مباشرة من زر الميكروفون.
- حد التسجيل الصوتي: دقيقتان.
- تشغيل الرسالة الصوتية من داخل المحادثة.
- الصور والملفات تُرفع إلى Supabase Storage داخل bucket خاص اسمه `chat-media`.
- المرفقات الخاصة لا تُعرض إلا للمشاركين في المحادثة حسب سياسات Supabase.
- الحد الأقصى للصورة 8MB وللصوت 12MB.

### مهم جدًا
بعد رفع ملفات v2.4 شغّل `supabase.sql` الجديد في Supabase SQL Editor.

### بالنسبة إلى APK
رفع الصور يعمل عادةً في WebView إذا كان اختيار الملفات مفعّلًا.
أما تسجيل الصوت داخل APK فقد يحتاج إضافة صلاحية `RECORD_AUDIO` إلى مشروع Android وإعادة بناء APK، لأن موقع GitHub Pages نفسه لا يستطيع منح صلاحية الميكروفون لتطبيق WebView.

# تاج الملوك — النسخة المصفاة الحالية

هذه هي النسخة الحالية المصفاة من المشروع بعد دمج التحديثات الفعالة وحذف ملفات التحديثات القديمة والواجهات غير المستخدمة.

## الملفات الأساسية
- `index.html` — الواجهة الرئيسية والأقسام الحالية.
- `style.css` — التصميم والحركات والتوافق مع الهاتف.
- `app.js` — التنقل، الثيم، اللغة ووظائف الواجهة العامة.
- `account.js` — تسجيل الدخول، الحساب، الكود وحالة الاشتراك.
- `developer.js` — لوحة المطور وإدارة المحتوى والحسابات.
- `game-store.js` — عرض التطبيقات والألعاب، الفتح المباشر والتنزيل المحمي.
- `store.js` — قسم المتجر.
- `links-store.js` — الروابط الرسمية.
- `supabase-config.js` — إعداد اتصال Supabase وR2 Worker.
- `supabase-v27-open-url.sql` — تحديث قاعدة البيانات المطلوب للفتح المباشر.
- `crown-logo.svg` و `gaming-hero.jpg` — ملفات الواجهة المستخدمة حاليًا.

## منطق الفتح والتنزيل
- **فتح مباشر:** لا يحتاج تسجيل دخول أو كود، ويستخدم `open_url`.
- **تنزيل:** يحتاج حسابًا مسجلًا ثم كود اشتراك فعال قبل بدء تنزيل APK.

## إعداد Supabase
إذا لم تكن شغلت تحديث V27 سابقًا، شغّل ملف `supabase-v27-open-url.sql` مرة واحدة من Supabase SQL Editor.

## ما تم حذفه في التصفية
- ملفات README الخاصة بالتحديثات V24/V25/V26/V27 القديمة.
- ملف README القديم الذي يحتوي تعليمات V14/V23/V24.
- واجهات تحميل المتجر والمحاكي والألعاب المدفوعة القديمة التي لم تعد موجودة في القائمة الحالية.
- بطاقات التطبيقات والألعاب السحابية التجريبية الثابتة القديمة؛ المحتوى الحالي يأتي من لوحة المطور.

> ملاحظة: تم الإبقاء على طبقات التوافق الداخلية التي ما زالت تعتمد عليها الحسابات ولوحة المطور لتجنب كسر الوظائف الحالية.

# 👑 منصة تاج الملوك | Crown of Kings Platform

منصة رقمية ملكية عصرية متكاملة للتطبيقات والألعاب والخدمات السحابية وأكواد التفعيل الحصرية، بتصميم كلاسيكي عصري فاخر ومريح للعين ينبض بألوان النيون الملكية، تدعم التصفح المباشر كزائر ومتوافقة 100% مع الهواتف الذكية وأجهزة الآيباد والتابلت وأجهزة الحاسوب PC.

---

## 🌟 مميزات المنصة (Key Features)

### 1. 👑 الهيدر والشريط العلوي الذكي
- **الشريط العلوي (Top Utility Bar)**: شريط إعلانات وأخبار متحرك (Ads Ticker) + زر التبديل الفوري بين الوضعين (النهاري اللؤلؤي ☀️ / الليلي الملكي 🌙) + مبدل اللغة الفوري (عربي / English) + مؤشر حالة الزائر.
- **الهيدر الرئيسي**:
  - **اليمين**: شعار وصورة متجر تاج الملوك النيوني النابض بالحياة.
  - **الوسط**: اسم المنصة "تاج الملوك" بخط عربي ملكي وإضاءة خلفية ذهبية.
  - **اليسار**: زر الـ 3 شرطات (Hamburger) المتحرك لفتح القائمة الجانبية.

### 2. 📱 القائمة الجانبية المنبثقة (49% Sidebar Drawer)
- تنبثق بنسبة **49%** من يمين الشاشة على الحواسيب والآيباد مع خلفية بلورية ناعمة.
- تضم الـ **12 قسماً** الملكية بالكامل:
  1. **الرئيسية (Home)**: واجهة المنصة وأحدث العروض والأخبار.
  2. **شراء كود (Buy Code)**: باقات الاشتراك الفضية، الذهبية، والملكية مع توليد فوري لأكواد الشراء وطرق الدفع الآمنة.
  3. **تفعيل كود (Activate Code)**: نظام فحص وتنشيط فوري للأكواد مع تأكيد الصلاحية وإشعارات النجاح.
  4. **تحميل المتجر (Download Store)**: روابط وتفاصيل تحميل تطبيق المتجر للأندرويد (APK)، الآيفون والآيباد (iOS)، والكمبيوتر (Windows EXE).
  5. **التطبيقات (Apps)**: مكتبة التطبيقات المعدلة وتطبيقات بلس مع نظام فلترة وبحث فوري.
  6. **العاب (Games)**: أشهر الألعاب المهكرة والمعدلة بمعدل 90 و 120 إطاراً في الثانية.
  7. **العاب سحابية (Cloud Games)**: تشغيل ألعاب PC و PS5 السحابية مباشرة من المتصفح بجودة 4K و 60FPS بدون الحاجة لتحميل أو مواصفات عالية.
  8. **الروابط (Links)**: القنوات الرسمية (تلغرام، ديسكورد، يوتيوب، والسيرفرات البديلة).
  9. **المحاكي (Emulators)**: محاكيات أندرويد وكونسول PC مع شرح إعدادات أعلى أداء.
  10. **العاب مدفوعة (Paid Games)**: ألعاب VIP العالمية المدفوعة مفتوحة مجاناً للزوار والأعضاء.
  11. **تسجيل دخول (Login / Account)**: نافذة الحساب مع إمكانية التصفح الدائم كزائر مباشر بدون قيود.
  12. **الاعدادات (Settings)**: تخصيص المظهر، إيقاف/تفعيل النيون، المؤثرات الصوتية الملكية، ومسح الذاكرة المؤقتة.

### 3. 🖥️ شاشات الأقسام المنبثقة بكبر الجهاز (Full-Device Views)
- عند الضغط على أي قسم، تنبثق شاشة بكبر الجهاز بالكامل مع زر **"رجوع إلى الرئيسية"** فوري ومريح للرجوع بلمسة واحدة.

### 4. 🤖 بوت المساعدة التفاعلي (Crown AI Bot)
- زر عائم سفلي بنبضات نيون.
- محادثة تفاعلية تجيب فورياً على الأسئلة الشائعة (تفعيل الكود، تحميل المتجر، الألعاب السحابية، والدعم الفني).

### 5. 🌐 دعم ثنائي اللغة والوضع النهاري/الليلي
- إمكانية تحويل كامل نصوص المنصة إلى الإنجليزية أو العربية فورياً دون أي تأخير أو تغيير في هيكل الأقسام.

## 🚀 طريقة التشغيل والرفع على GitHub و GitHub Pages

### التشغيل المحلي:
افتح ملف `index.html` في أي متصفح (Chrome, Firefox, Safari, Edge) وستعمل المنصة فوراً بدون أي خوادم خارجية أو حزم إضافية.

### الرفع على GitHub:
1. أنشئ مستودعاً جديداً (New Repository) على حسابك في GitHub باسم: `taj-al-molook`.
2. داخل مجلد المشروع، قم بتنفيذ الأوامر التالية في الطرفية (Terminal / PowerShell):
```bash
git init
git add .
git commit -m "الإطلاق الرسمي لمنصة تاج الملوك V3.0"
git branch -M main
git remote add origin https://github.com/USERNAME/taj-al-molook.git
git push -u origin main
```

### التفعيل على GitHub Pages (استضافة مجانية بنقرة واحدة):
1. اذهب إلى إعدادات المستودع على GitHub: **Settings > Pages**.
2. تحت قسم **Branch**، اختر `main` واضغط **Save**.
3. سيكون رابط منصتك متاحاً للجميع عالمياً على:
`https://USERNAME.github.io/taj-al-molook/`

## V13 performance/theme fix
- Gaming Mode now overlays accents/effects on the currently selected Day/Night theme instead of forcing a dark palette.
- Removed fixed full-screen grid/gradient rendering, icon drop-shadow filters, card box-shadow effects, and infinite name glow animation from Gaming Mode.
- Navigation sound is throttled to reduce repeated WebAudio work during rapid clicks.

## V14 — Standalone Gaming Mode
- Gaming Mode is now a third primary theme, independent of Day/Night.
- Enabling Gaming Mode suspends the Day/Night selector and uses the gaming palette everywhere.
- Disabling it restores the Day/Night mode that was active before Gaming Mode.
- Heavy blur, shadows and continuous effects are removed for smoother navigation.

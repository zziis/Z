تاج الملوك V6 — متجر الأكواد بالنقاط

1) يجب أن تكون V5 مهيأة مسبقًا.
2) ضع Publishable/anon key فقط داخل supabase-config.js.
3) في Supabase > SQL Editor شغّل ملف supabase-v6.sql مرة واحدة بعد supabase-v5.sql.
4) حساب المطور: افتح لوحة المطور، ومن قسم "متجر النقاط" أنشئ بطاقة كود وحدد النوع والمدة والسعر بالنقاط.
5) من قائمة المستخدمين اضغط "نقاط" لإضافة/خصم نقاط من الحساب.
6) المستخدم يرى رصيده في بطاقة الحساب وفي صفحة شراء كود. عند الشراء، الخصم وتوليد الكود يتمان داخل قاعدة البيانات كعملية واحدة.
7) الكود الذي يشتريه المستخدم يصبح مخصصًا لحسابه ولا يستطيع حساب آخر تفعيله.

أمان: لا تضع service_role أو Secret key في GitHub Pages. استخدم Publishable/anon key فقط مع RLS/RPC.

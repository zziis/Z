تاج الملوك V5
1) افتح supabase-config.js وضع Publishable/anon key فقط.
2) في Supabase > SQL Editor شغّل supabase-v5.sql مرة واحدة.
3) أنشئ حساب المطور من المنصة، ثم في SQL Editor نفّذ السطر الأخير بعد استبدال البريد.
4) لوحة المطور يمكن فتحها من Console مؤقتاً بالأمر tajV5.admin()؛ ويمكن لاحقاً ربطها بزر خاص لا يظهر إلا للمطور.
5) بيانات الحساب والأكواد والصلاحيات محفوظة في Supabase ومحكومة بـ RLS/RPC، وليس localStorage.
ملاحظة: واجهة نشر التطبيقات الحالية لم تُحوّل بعد إلى تخزين Supabase في هذه النسخة؛ البنية الآمنة للحسابات/الأكواد/الحظر/الرسائل موجودة كأساس V5.
